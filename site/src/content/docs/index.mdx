## Before you arrive

Do this at home, on real wifi. It takes 10 to 15 minutes and needs Docker, kind, kubectl and helm.

```bash
git clone https://github.com/iblancasa/kiali-tracing-tutorial.git
cd kiali-tracing-tutorial
make prepare
```

## The system

```
loadgen -> ingress gateway -> frontend -+-> menu -+-> pricing -> promotions
                                        |         '-> reviews (v1, v2) -> ratings
                                        |
                                        '-> orders -+-> inventory -> redis
                                                    +-> payments -> fraud
                                                    +-> kitchen -> inventory
                                                    +-> delivery -> maps
                                                    '-> notifications
```

| What | Tool | Where |
|---|---|---|
| service mesh | [Istio](https://istio.io/) 1.32 | every pod of the shop has an Envoy sidecar |
| mesh console | [Kiali](https://kiali.io/) 2.35 | [localhost:20001](http://localhost:20001) |
| traces | [Jaeger](https://www.jaegertracing.io/) 2.23 | [localhost:16686](http://localhost:16686) |
| metrics | [Prometheus](https://prometheus.io/) | [localhost:9090](http://localhost:9090) |
| dashboards | [Grafana](https://grafana.com/oss/grafana/) | [localhost:3000](http://localhost:3000) |
| telemetry pipeline | [OpenTelemetry Collector](https://opentelemetry.io/docs/collector/) | between the proxies and Jaeger |
| auto-instrumentation | [OpenTelemetry operator](https://opentelemetry.io/docs/platforms/kubernetes/operator/) 0.164 | step 4 |
